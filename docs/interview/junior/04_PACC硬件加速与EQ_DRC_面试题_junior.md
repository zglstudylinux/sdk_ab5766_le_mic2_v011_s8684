## 1. 概念理解题

### 题目 4.1 PACC 是什么（★ / 概念理解）

**题目**：PACC 是什么？它主要处理哪类音频算法？

**考察点**：对硬件加速器的基本认知。

**参考答案**：
PACC 是芯片内置的音频处理硬件加速器，主要处理 EQ（均衡器）和 DRC（动态范围压缩）等算法，比 CPU 软件实现更快、更省电。

**评估标准**：
- ⭐⭐⭐ 能说出“硬件加速”+算法类型；
- ⭐⭐ 能说出“硬件加速”；
- ⭐ 完全不知道。

### 题目 4.2 EQ 和 DRC 的作用（★★ / 概念理解）

**题目**：请用一句话分别描述 EQ 和 DRC 在音频中的作用。

**考察点**：对音频算法的基本理解。

**参考答案**：
- EQ（均衡器）：调整不同频率的增益，改变音色；
- DRC（动态范围压缩）：自动压缩大信号、提升小信号，控制音量动态范围。

**评估标准**：
- ⭐⭐⭐ 能准确描述两个作用；
- ⭐⭐ 能描述其中一个；
- ⭐ 完全不知道。

### 题目 4.3 Soft Gain 与硬件增益的区别（★★ / 概念理解）

**题目**：Soft Gain 是什么？它与硬件 PGA 增益的区别是什么？

**考察点**：软件增益的位置与意义。

**参考答案**：
Soft Gain 是软件实现的数字增益，在 PCM 数据上逐点乘系数；硬件 PGA 在模拟/ADC 侧调节。Soft Gain 更灵活、可精细渐变，但会增加 CPU 或 PACC 负担。

**评估标准**：
- ⭐⭐⭐ 能区分软件/硬件位置；
- ⭐⭐ 能说出是软件增益；
- ⭐ 完全不知道。
