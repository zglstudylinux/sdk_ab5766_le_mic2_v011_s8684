## 1. 概念理解题

### 题目 7.1 蓝灯常亮/闪烁分别表示什么（★ / 概念理解）

**题目**：当前工程中，蓝灯常亮、慢闪、快闪分别表示什么状态？

**考察点**：
- 主考点：LED 状态显示；
- 副考点：`led_bt_idle()`、`led_bt_connected()`；
- 区分点：能否说出三种状态。

**参考答案**：
- 蓝灯常亮/特定闪烁：开机/关机状态；
- 慢闪：未连接/配对中（`led_bt_idle()`）；
- 快闪或特定 pattern：已连接（`led_bt_connected()`）。

**评估标准**：
- ⭐⭐⭐ 能说出三种；
- ⭐⭐ 说出两种；
- ⭐ 完全不知道。

---

### 题目 7.2 按键无反应先看什么（★★ / 概念理解）

**题目**：用户按 K1 音量+，但设备没反应。第一步应该看什么？

**考察点**：
- 主考点：按键问题初步排查；
- 副考点：`msg_mic_emit.c` 与连接状态；
- 区分点：能否说出“先看是否已连接”。

**参考答案**：
先看 TX 是否已与 RX 连接。因为 `msg_mic_emit.c` 中 `MSG_VOL_UP` 只在 `wireless_mic.connected_sta` 非 0 时才执行 `soft_gain_up()`；未连接时按键操作无效。

**评估标准**：
- ⭐⭐⭐ 能说出“先查连接”；
- ⭐⭐ 能说出“看按键”；
- ⭐ 完全不知道。

## 2. 调试排查题

### 题目 7.3 串口没任何输出（★★ / 调试排查）

**题目**：上电后串口没有任何输出。请给出至少 3 个可能原因。

**考察点**：
- 主考点：启动调试；
- 副考点：UART、电源、复位；
- 区分点：能否列出 3 个层级。

**参考答案**：
1. 电源/复位：板子没上电或复位脚被拉低；
2. UART 硬件：TX/RX 接反、波特率不对（应为 1.5Mbps）、GND 未共地；
3. 固件：`BSP_UART_DEBUG_EN` 配置错误或固件未烧录成功。

**评估标准**：
- ⭐⭐⭐ 3 个层级；
- ⭐⭐ 2 个；
- ⭐ 只说一句。

### 题目 7.4 耳机无声但无线已连接（★★ / 调试调试）

**题目**：RX 已连接（蓝灯快闪/常亮），但耳机无声。请给出至少 3 个可能原因。

**考察点**：
- 主考点：RX 音频链排查；
- 副考点：DAC、解码、mute；
- 区分点：能否区分“无线问题”与“音频问题”。

**参考答案**：
1. TX 端 mute：`MSG_VOL_MUTE` 被触发，TX 发送的是静音帧；
2. RX DAC 问题：`ADAPTER_DAC_OUTPUT_EN=0` 或 DAC0 未初始化；
3. 解码/PLC 问题：连续 BFI 导致 PLC 输出静音；
4. 音量过低：Soft Gain 在最低档。

**评估标准**：
- ⭐⭐⭐ 3+ 原因；
- ⭐⭐ 2 个；
- ⭐ 只说一句。
