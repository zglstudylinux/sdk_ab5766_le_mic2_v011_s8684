> 岗位：初级嵌入式工程师
> 核心考察：RX 基本概念、PLC 作用、DAC 输出位置

## 0. 项目上下文速览

- 芯片/项目：AB5766 RISC-V LE Mic 无线麦克风 RX 端（Adapter/适配器）。
- 音频链：无线接收 → BFI/PLC → LC3S 解码 → MIX_DRC → DAC 输出到耳机。
- 本卷重点：RX 基本概念与数据流方向。

## 1. 概念理解题

### 题目 3.1 RX 的输入是什么？（★ / 概念理解）

**题目**：RX（Adapter）的音频数据从哪里来？

**考察点**：RX 的物理输入源。

**参考答案**：
来自 2.4G 无线链路，由 TX（麦克风发射端）通过蓝牙/私有协议发送的 LC3S 压缩音频包。

**评估标准**：
- ⭐⭐⭐ 能说出无线/蓝牙来源；
- ⭐⭐ 能说出“从 TX 来”；
- ⭐ 完全不知道。

---

### 题目 3.2 PLC 的作用（★★ / 概念理解）

**题目**：PLC（Packet Loss Concealment）在 RX 中的作用是什么？请用一句话说明。

**考察点**：对 PLC 功能的理解。

**参考答案**：
当无线包丢失时，用历史音频数据预测/插值出丢失的音频，避免声音中断或爆音。

**评估标准**：
- ⭐⭐⭐ 能说出“丢包补偿/隐藏”；
- ⭐⭐ 能说出大概；
- ⭐ 完全不知道。

## 2. 源码追踪题

### 题目 3.3 DAC 输出调用的位置（★★ / 源码追踪）

**题目**：RX 解码并处理后的 PCM 数据，最终通过哪个函数送到 DAC？

**考察点**：`dac0_out_audio_input()` 的调用位置。

**参考答案**：
在 [modules/wireless/mic_proc.c:465](modules/wireless/mic_proc.c#L465) 或 [mic_proc.c:511](modules/wireless/mic_proc.c#L511) 的 `mic_dec_pcm_out()` 中，调用 `dac0_out_audio_input()` 把 PCM 送给 DAC。

**评估标准**：
- ⭐⭐⭐ 能说出函数名；
- ⭐⭐ 能说出位置；
- ⭐ 完全不知道。
